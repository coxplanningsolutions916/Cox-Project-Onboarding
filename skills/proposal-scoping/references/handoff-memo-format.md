# Handoff Memo Format

The structured memo the proposal coordinator turns into the Automator/PandaDoc client document. Produced only after Chris approves scope, budget, timeline, and payment.

```
PROPOSAL HANDOFF MEMO
For: Michelle Ross — Cox Planning Solutions
Prepared by: Chris Cox via Claude
Date: [Date]
─────────────────────────────────────────────────────────
PROPOSAL TYPE: New Proposal
CLIENT: [Full legal entity name]
CONTACT: [Name, email if known]
PROJECT: [Short descriptive title]
DDL STEP: Step [#] — [Name]  /  N/A — [Scope Type]
AUTOMATOR TEMPLATE: [Step X template / Subscription / Custom]
DRIVE FOLDER: Sales/Proposals/[Client Name]/
─────────────────────────────────────────────────────────
INTRODUCTION (Chris's voice — first-person plural, plain language)
[2–4 paragraphs: site/project context, what Cox has done so far, what this
scope covers, and what decision the client can make when it is complete.
No oversell. No guaranteed-approval language.]
─────────────────────────────────────────────────────────
SCOPE OF WORK

Phase 0 — Project Management
  [PM items, or: Included in deliverable fees]

Phase [#] — [Name]
  [Code] [Deliverable Name]
  [One-to-two sentence description for the proposal body]
  Fee: $[Amount]  |  Billing: Fixed Fee / T&M NTE / Subscription

[Repeat for each phase in scope]

Total Fee: $[Amount] ([billing type])
─────────────────────────────────────────────────────────
PAYMENT SCHEDULE
  Payment 1 ([%] / $[Amount]): [Milestone trigger]
  Payment 2 ([%] / $[Amount]): [Milestone trigger]
  Payment 3 ([%] / $[Amount]): [Milestone trigger]
  — OR —  T&M: Monthly, NTE $[Amount], 30-day terms, 1% monthly late fee.
  — OR —  Subscription: $[Amount]/[month|year]; free trial [terms]; founding rate [if any].
─────────────────────────────────────────────────────────
TIMELINE
  [Phase]: [Month range or duration]
  [Items outside Cox's control]
─────────────────────────────────────────────────────────
STANDARD AGREEMENT
  [ ] New — attach Articles 1–9
  [ ] Existing — reference: [Original agreement date / Task Order]
─────────────────────────────────────────────────────────
SIGNER / SIGNATURE BLOCK
  Consultant: Chris Cox / Cox Planning Solutions
  Client: [Client name / authorized representative]
  [Chris updates the signer before sending; leave client block for Chris to confirm]
─────────────────────────────────────────────────────────
OPEN ITEMS — CHRIS TO CONFIRM BEFORE SENDING
  [ ] [Unresolved items, missing info, flags]
─────────────────────────────────────────────────────────
INTERNAL FEE BACKUP (do not include in proposal)
  [Role | Hrs | Cost basis | Cash cost | MSRP value, per deliverable]
  [Proposed fee vs. cost floor; document variance / margin]
```
