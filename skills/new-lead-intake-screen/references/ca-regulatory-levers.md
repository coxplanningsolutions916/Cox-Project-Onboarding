# California Regulatory Levers

A screening reference for the state reform-law pathways that can unlock development potential beyond base zoning. Used in Stage 5.4 to flag candidates for the findings email and the proposed ISR scope.

> **Scope of use.** This file supports the **initial strategic screen**, not the paid analysis. In the free screen, name the plausible pathway, cite the governing code, and note the obvious disqualifiers — nothing more. The defensible determination (eligibility, exact yield, interaction with local ordinances and Housing Element status) is a Step 1 ISR deliverable. Never present a lever as secured.

> **Maintenance.** California amends housing law nearly every legislative cycle; section numbers shift on recodification (the ADU statutes were recodified in 2025). Verify current text before relying on any entry in paid work. This file is the single source of truth shared by the intake screen and ISR-stage regulatory analysis — update it once, in one place. Candidate canonical home: Cox Operations Manual (regulatory reference) or Component Library. Backfill lessons from each ISR (most recently A-Plus Construction) here.

## How to use in the screen

1. Start from the zoning and General Plan designations (Stage 5.1).
2. Match the prospect's intent (residential yield, conversion, subdivision, redevelopment) to the pathways below.
3. Flag the one or two with the strongest fit. For residential infill, prefer the simplest ministerial path that delivers the yield — ADU pathways routinely outperform density bonus on unit count and regulatory simplicity (ministerial, no CEQA, no affordability covenant, no prevailing wage).

## Levers

### ADU / JADU (ministerial)
- **Unlocks:** Additional ministerial units on residential lots — primary + detached ADU + JADU stacking; no CEQA, no affordability covenant, no prevailing wage.
- **Citation:** Gov. Code §66310 et seq. (recodified; formerly §65852.2 / §65852.22). Exempt stacking interactions at §66323.
- **Disqualifiers / notes:** Size, height, and setback limits apply; HOA/CC&R and some overlay constraints interact. Strongest lever for single-lot and small-infill residential.

### SB 9 — two-unit and urban lot split (ministerial)
- **Unlocks:** Up to two units per lot plus a ministerial urban lot split (potential 4 units across the split), in single-family zones.
- **Citation:** Gov. Code §65852.21 (two-unit) and §66411.7 (lot split).
- **Disqualifiers / notes:** Urban single-family parcels only; owner-occupancy affidavit on lot splits; exclusions for historic, prime farmland, high fire, and certain protected parcels. Yield often trails stacked ADUs once standards are applied.

### State Density Bonus Law
- **Unlocks:** Density above base, plus concessions/incentives and waivers of standards, in exchange for affordable units.
- **Citation:** Gov. Code §65915; expanded stacking under AB 1287.
- **Disqualifiers / notes:** Requires affordability set-aside and covenants; triggers prevailing wage on some projects. Compare against ADU yield before recommending — density bonus carries more strings.

### SB 330 — Housing Crisis Act
- **Unlocks:** Preliminary application vesting (freezes standards/fees), limits on downzoning and added standards, no-net-loss / replacement obligations on protected units.
- **Citation:** Gov. Code §66300 et seq.; preliminary application vesting at §65941.1.
- **Disqualifiers / notes:** A protective lever more than a yield lever. Replacement obligations can cut the other way on redevelopment of existing rental — screen for protected units early.

### SB 35 / SB 423 — ministerial streamlining
- **Unlocks:** Ministerial, CEQA-exempt approval for qualifying multifamily housing in jurisdictions behind on RHNA.
- **Citation:** Gov. Code §65913.4 (SB 35; extended/amended by SB 423).
- **Disqualifiers / notes:** Affordability and labor/prevailing-wage standards apply by tier; site exclusions (wetlands, farmland, fire, historic). Eligibility depends on the jurisdiction's RHNA progress.

### AB 2011 — Affordable Housing and High Road Jobs Act
- **Unlocks:** Ministerial residential on commercial-corridor / office-retail-parking zoned sites.
- **Citation:** Gov. Code §65912.100 et seq.
- **Disqualifiers / notes:** Corridor width and site criteria; affordability and labor standards. Powerful where base zoning is commercial and the prospect wants housing.

### AB 2097 — parking minimum elimination
- **Unlocks:** Removes local minimum parking requirements within one-half mile of major transit.
- **Citation:** Gov. Code §65863.2.
- **Disqualifiers / notes:** Proximity to qualifying transit required. Frees site area and improves yield/feasibility; pairs with the housing pathways above.

### Housing Accountability Act / Builder's Remedy
- **Unlocks:** Constrains denial of compliant housing; Builder's Remedy applies where the jurisdiction lacks a compliant Housing Element.
- **Citation:** Gov. Code §65589.5.
- **Disqualifiers / notes:** Builder's Remedy is fact-sensitive and politically contested; flag as a possibility for counsel/ISR analysis, not a casual recommendation.

### SB 684 / SB 1123 — small-lot / starter-home subdivision streamlining
- **Unlocks:** Ministerial subdivision and approval for small multi-unit/starter-home projects on qualifying lots.
- **Citation:** SB 684 (2023) / SB 1123 (2024); verify current code placement before relying.
- **Disqualifiers / notes:** Lot size and zoning criteria; newest pathway — confirm live text and local implementation.

### Williamson Act (constraint lever)
- **Unlocks / constrains:** Agricultural land under contract carries tax benefits but restricts development; nonrenewal or cancellation is required before conversion.
- **Citation:** Gov. Code §51200 et seq.
- **Disqualifiers / notes:** A constraint to surface, not an unlock. Nonrenewal runs ~10 years; cancellation carries penalties. Flag if the parcel is in an ag preserve.

### Ellis Act (rental withdrawal)
- **Unlocks / constrains:** Permits withdrawal of rental units from the market for redevelopment, subject to local replacement/relocation rules.
- **Citation:** Gov. Code §7060–7060.7.
- **Disqualifiers / notes:** Interacts heavily with local ordinances (e.g., LA replacement-unit determinations). Surface where redevelopment displaces existing rental.
