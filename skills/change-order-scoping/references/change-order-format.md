# Change Order Memo Format

Same handoff memo as a new proposal, with PROPOSAL TYPE set to "Change Order" and a Change Order Summary section inserted ahead of the Scope of Work.

```
PROPOSAL HANDOFF MEMO
For: Michelle Ross — Cox Planning Solutions
Prepared by: Chris Cox via Claude
Date: [Date]
─────────────────────────────────────────────────────────
PROPOSAL TYPE: Change Order
CLIENT: [Full legal entity name]
CONTACT: [Name, email if known]
PROJECT: [Short descriptive title]
AUTOMATOR TEMPLATE: Change Order template
DRIVE FOLDER: Sales/Proposals/[Client Name]/[Project Name]/Change Orders/
─────────────────────────────────────────────────────────
CHANGE ORDER SUMMARY
  Original Task Order: [#] — [Name]
  Original NTE / Fixed Fee: $[Amount]
  Change Order Amount: +/- $[Amount]
  Revised Total: $[Amount]
  Reason for Change: [Brief factual description]
─────────────────────────────────────────────────────────
INTRODUCTION (what changed and why — not the original project context)
[1–2 paragraphs.]
─────────────────────────────────────────────────────────
SCOPE OF WORK — CHANGES ONLY
  Added:
    [Code] [Deliverable Name] — [description]   Fee: $[Amount]
  Removed:
    [Code] [Deliverable Name]                    Credit: $[Amount]
  Net fee adjustment: +/- $[Amount] ([billing type])
─────────────────────────────────────────────────────────
PAYMENT
  Single milestone: [Upon signature | Upon added deliverable] — $[Amount]
─────────────────────────────────────────────────────────
TIMELINE
  [Impact of the change on the existing schedule]
─────────────────────────────────────────────────────────
STANDARD AGREEMENT
  [x] Existing — reference: [Original agreement date / Task Order #]  (do not re-attach)
─────────────────────────────────────────────────────────
OPEN ITEMS — CHRIS TO CONFIRM BEFORE SENDING
  [ ] [Flags]
─────────────────────────────────────────────────────────
INTERNAL FEE BACKUP (do not include) — changed scope only
  [Role | Hrs | Cost basis | Cash cost vs. proposed adjustment | margin]
```
